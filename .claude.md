# Instruções para o Claude

## Contexto

O Tabularium está em fase inicial. Não presuma arquitetura, linguagem, framework, banco de dados ou requisitos que ainda não estejam registrados no repositório.

## Diretrizes de trabalho

- Leia `README.md`, `.docs/BOAS_PRATICAS.md` e os arquivos relacionados antes de alterar o projeto.
- Preserve mudanças existentes do usuário e mantenha cada alteração dentro do escopo solicitado.
- Prefira soluções simples, legíveis e compatíveis com as convenções já adotadas.
- Não invente comandos, dependências, APIs, credenciais ou comportamentos.
- Nunca exponha ou versione segredos. Use variáveis de ambiente e mantenha `.env.example` sem valores sensíveis quando necessário.
- Atualize a documentação quando a configuração, o uso ou a arquitetura mudar.

## Qualidade e validação

- Adicione ou atualize testes proporcionais à mudança.
- Execute os testes, o linter, o formatador e o build disponíveis antes de concluir.
- Informe claramente o que foi validado e qualquer limitação restante.
- Use commits no padrão Conventional Commits quando um commit for solicitado.
